# Legacy (v1) material for Part 2

The two notebooks of the last v1 release (v1.1.0): the inorganic surrogate (`01_inorganic_surrogate_notebook_v1.ipynb`)
and the organic–inorganic combination with the descriptor-based organic surrogate and the OOD guard
(`02_combination_notebook_v1.ipynb`). They are superseded by `../01_part2_revision.ipynb`, which corrects the
training protocol, compares with Fortran reference output, uses the Part 1 R_emb organic surrogate, separates the
guard's calibration and test organics, and adds the comparison with experimental data. They are kept only for
traceability of the earlier version. They cannot be run from this folder; the complete v1 state, including the
`*_bundle.zip` files, is available under the git tag `v1.1.0`.
