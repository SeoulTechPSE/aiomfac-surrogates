# Part 1 — Organic surrogate

Reproduces every table and figure in Part 1 of the paper series (feature-representation ablation, GNN
comparison, halogen-coverage finding, Tg-aware viscosity pipeline, Sobol GSA, and the CPU speed benchmark).

## Contents

- `01_organic_surrogate_notebook.ipynb` — the full reproduction notebook (executed; outputs saved).
- `bimog_unified.json` — the 368-compound BIMOG training pool (Armeli Iapichino, Peters and Koop, 2023),
  consumed directly by the notebook.
- `trained_model_delivered/` — the saved hand-crafted-feature MLP checkpoint (Table 1 row B / Table 2
  Model A). Used for every result in this paper except Sec. 3.11's worked-example check (see below).
- `trained_model_dense/` — a second checkpoint, identical architecture/features/molecule split, trained on
  a denser, fixed water-mass-fraction composition grid (200 points/molecule instead of 20 random-jittered
  ones). Produced by `train_dense_surrogate.py` and used only for Sec. 3.11's worked-example validation
  (notebook Sec. 8) and by Part 2's combination notebook (Sec. 4), which is more accurate on those checks.
- `train_dense_surrogate.py` — standalone script that trains `trained_model_dense/`; run it from this
  directory (expects `bimog_unified.json` next to it, same as the main notebook).
- `benchmark_speed.py`, `benchmark_numpy.py` — the standalone speed-benchmark script behind Tables 4-5
  (PyTorch vs. plain-NumPy forward pass, one-at-a-time vs. batched), runnable outside the notebook.
- `make_figures.py` — regenerates `figs/*.png` from the saved result JSONs.
- `timing_results.json`, `timing_results_gpu_run.json`, `sobol_results.json` — raw numeric results behind
  Tables 1-5 and the Sobol indices, cached so figures/tables can be regenerated without re-running the full
  notebook.
- `figs/` — the paper figures: the first six generated by `make_figures.py`, plus `fig7_worked_examples.png`
  (Sec. 3.11 worked-example check against published AIOMFAC figures), generated by the main notebook's own
  Sec. 8 cells.

## Running

Open `01_organic_surrogate_notebook.ipynb` in Jupyter or Google Colab and run all cells top to bottom; it
installs `aiomfac_py` and its own dependencies (PyTorch, RDKit, SALib) automatically if they are not already
present. A full run (feature ablation + GNN training with synthetic-pool pretraining + viscosity pipeline +
Sobol GSA + speed benchmark) takes several minutes on CPU.

The notebook's GPU-run numbers in Section 3.10 of the paper were obtained by running the same notebook's
speed-benchmark cell on a Google Colab T4 GPU runtime; the logic auto-detects `torch.cuda.is_available()`
and adds GPU timing when one is present.
